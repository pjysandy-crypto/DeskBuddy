# DeskBuddy
Windows 바탕화면 펫, 업무 퀘스트, 집중 모험, 꾸미기, 펫 배구.

## 실행
dist/DeskBuddy.exe를 더블클릭하거나 프로젝트의 DeskBuddy-START.cmd를 실행하세요. ZIP은 먼저 전체 압축을 해제하세요. .NET Framework 4.x가 있는 Windows 10/11용입니다. Python/Node.js/계정은 필요하지 않습니다.

펫 더블클릭: 메뉴 / 드래그: 이동 / 우클릭: 빠른 메뉴와 배구.
메뉴 창 X는 메뉴만 닫습니다. 완전 종료는 옵션 또는 펫 우클릭의 종료입니다. 이미 실행 중일 때 재실행하면 기존 메뉴가 열립니다.
시작 기록: %LOCALAPPDATA%/DeskBuddy/startup.log.

## 캐릭터와 크기
캐릭터 메뉴에서 기본 이미지 6개 중 선택하거나 PNG/JPG/BMP와 이름을 변경합니다. 기본 캐릭터는 img/Character/jiyoung_ch.png이며 6개 PNG는 실행파일에 포함됩니다. PNG 원본의 가로·세로 비율과 투명도를 유지하며, 이동 방향이 바뀌어도 가져온 이미지를 좌우반전하지 않습니다. 이름 저장 또는 Enter를 누르면 사이드바·상단·방 제목·펫 창 이름에 반영됩니다. 이미지를 바꿔도 이름은 유지됩니다. '샘플 여러 개 추가'로 추가 이미지들을 등록하면 선택 목록과 설정이 저장됩니다.

나의 방의 '옆돌기' 또는 펫 우클릭의 '옆돌기!'로 회전하며 이동합니다. 산책 중에도 가끔 옆돌기를 하며, 우클릭에서 자동 옆돌기를 켜고 끌 수 있습니다. 드래그·집중·게임 중에는 옆돌기를 멈춥니다.

캐릭터 메뉴의 '바탕화면 크기' 슬라이더로 40~320px 사이에서 즉시 조절합니다. 숫자와 설정이 저장되고 기본 버튼으로 140px로 되돌립니다. 게임 선수와 메뉴 미리보기 크기는 일정하게 유지됩니다. 작은 원본의 디테일을 자동 생성하거나 JPG의 배경을 제거하지는 않습니다. 이미지는 10MB/4096px 이내를 지원합니다. 액세서리는 고정 위치라 이미지 형태에 따라 위치가 다를 수 있습니다.

## 바탕화면 배구
펫 배구 메뉴의 '바탕화면 배구 시작' 또는 펫 우클릭의 배구를 선택하세요. 메뉴와 펫이 잠시 숨겨지고, 바탕화면 배경이 비치는 900x540 코트가 열립니다. 내 캐릭터와 컴퓨터 친구가 먼저 5점을 얻는 경기입니다.

- ENTER 또는 시작 버튼: 경기 시작/일시정지 후 계속
- 좌우 방향키 또는 A/D: 이동
- SPACE, 위 방향키 또는 W: 점프
- 아래 방향키 또는 X: 스매시
- ESC 또는 P: 일시정지
- R: 새 경기
- 우측 X 또는 Alt+F4: 배구 종료
- 상단 점수판 드래그: 코트 위치 이동

공의 중력, 캐릭터 충돌, 네트/벽 반사, 낙하지점 예측 AI를 사용합니다. 다른 앱으로 전환하면 자동으로 일시정지합니다. 게임으로 돌아와 점수판을 클릭한 뒤 ENTER로 이어서 하세요. 집중 타이머 진행 중에는 시작하지 않습니다.

승리 20코인, 패배 5코인. 경기 완료 보상은 하루 3회이며 이후에도 보상 없이 플레이할 수 있습니다. 중도 종료는 보상을 주지 않습니다. 날짜는 PC 로컬 날짜 기준이며 이전 별 잡기의 보상 횟수도 같은 일일 횟수에 포함됩니다. 이전 별 잡기는 배구로 교체됐습니다.

## 마법의 성 모험

미니게임의 '마법의 성 모험 시작' 또는 펫 우클릭으로 실행합니다. 1탄 '작은 성'은 기존 맵입니다. 클리어 화면에서 Enter 또는 다음 탄 시작 버튼으로 2탄 '바람의 탑', 3탄 '어둠의 성'을 순서대로 진행합니다. 매 탄 별 3개를 모은 뒤 꼭대기의 문에 도착하면 클리어합니다. 다음 탄에서 별과 몬스터가 새로 배치되고 생명이 3개로 회복됩니다. 2탄은 더 좁은 발판과 많고 빠른 몬스터, 3탄은 더 좁고 엇갈린 발판과 더 빠른 몬스터가 등장합니다. 3탄의 보라색 몬스터는 마법을 두 번 맞혀야 쓰러집니다. 몬스터와 닿으면 생명이 줄고 잠깐 무적이 됩니다. 생명을 모두 잃거나 R을 누르면 1탄부터 다시 도전합니다.

- Enter / 중앙 버튼: 시작 또는 계속
- 방향키 / A·D: 이동, Space / 위 / W: 점프
- Z / X: 마법 공격
- Esc / P: 일시정지, R: 처음부터 다시 시작
- 창 X: 게임 종료, 다른 앱으로 전환하면 자동 정지

1·2탄 완료에는 보상이 없으며 3탄까지 모두 클리어하면 +50 G를 한 번 지급하고 저장합니다. 실패 +5 G. 기존처럼 배구와 합산 하루 3회 보상이며 중도 종료는 보상이 없습니다. 집중 중에는 실행할 수 없습니다.

## 업무 / 집중 / 꾸미기
일정 완료 +20코인, 집중 완료 1분당 +1코인. 완료/보상 중복을 방지합니다. 일정은 10분 뒤 다시 알림이 가능합니다. 집중은 1~120분, 집중 중 산책은 정지합니다. 업무 완료 20 EXP와 집중 1분 1 EXP를 계산해 100 EXP마다 표시 레벨이 오릅니다. 상점에서 리본/모자/하트/왕관을 구매하고 재장착합니다.

알림은 앱 실행 중에 동작하며 절전 복귀/재실행 시 놓친 미완료 일정은 한 번 알립니다. Windows 알림 표시 여부는 OS 설정에 영향을 받습니다. 집중은 실제 PC 사용을 감지하지 않고 저장된 종료 시각을 기준으로 합니다. 앱 종료/절전 중 경과한 시간도 포함합니다.

## 저장
%LOCALAPPDATA%/DeskBuddy/data.json에 일정·코인·크기·집중 종료 시각·아이템을 저장합니다. 이전 저장은 data.json.bak, 손상된 원본은 .damaged-*로 보관합니다. 가져온 이미지는 같은 폴더에 복사합니다. 옵션의 백업은 JSON을 내보내며 이미지 파일은 별도 보관하세요. 자동 복원 UI는 없습니다.

## 개발
PowerShell:
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test -Preview

- DeskBuddy.cs: 저장, 보상, 원본 이미지 렌더러, 바탕화면 펫
- PixelUI.cs: 도트 UI, 방, 크기 슬라이더, 게임 실행 메뉴
- AlphaWindow.cs: 픽셀별 알파 합성(UpdateLayeredWindow)
- Volleyball.cs: 배구 물리, AI, 키보드, 득점, 투명 코트
- Castle.cs: 성 모험 물리, 별 수집, 마법 공격, 키 조작, 보상
- CharacterLibrary.cs: 내장 PNG와 추가 샘플 선택 목록
- assets/neodgm.ttf: 실행파일에 포함하는 Neo둥근모 글꼴
- --self-test: 업무/집중/아이템/배구 물리 규칙
- --ui-test: 실제 메뉴 버튼과 슬라이더, 설정 변경/저장
- --volley-test: 물리, 득점, 보상, 실제 게임 창의 키 핸들러와 일시정지/재개, 투명 창
- --castle-test: 발판, 점프, 공격, 수집, 무적, 승패, 보상과 실제 창의 키 핸들러
- --image-test 이미지경로: 원본, 비율, 반투명, 실제 분홍색, 좌우 방향 유지
- --preview: 샘플 데이터로 메뉴 화면 생성
- dist/preview: 검증용 미리보기

테스트는 별도 임시 데이터를 사용합니다. 게임 창 키 핸들러 검사는 테스트 입력을 창 이벤트에 전달하며 전역 키보드 입력을 보내지 않습니다. 실제 키보드와 Windows 10/11, 화면 배율, 여러 모니터 환경의 사용성은 수동 확인이 필요합니다.

## 발표
퀘스트 → 완료 보상 → 꾸미기를 먼저 보여준 후 캐릭터 선택, 옆돌기, 배구와 성 모험을 시연하세요. 옆돌기는 원본 이미지를 회전하는 동작입니다. Outlook/Teams 연동과 캐릭터별 관절 애니메이션은 후속 과제입니다.

Neo둥근모 공식 출처: https://github.com/neodgm/neodgm-webfont
글꼴 SIL OFL 1.1 전문은 assets/FONT-LICENSE.txt 및 dist/FONT-LICENSE.txt에 포함합니다.
기본 캐릭터와 샘플은 img/Character의 제공된 원본 이미지입니다. 공개 제품화에는 자체 캐릭터 또는 사용 허가가 있는 이미지를 사용하세요.

## 일정 설정
퀘스트 보드의 '+ 일정 추가'를 누르면 픽셀 일정 편집 창이 열립니다. 날짜는 Krypton 달력으로 선택하고 시간은 09:00처럼 직접 입력하거나 15분 목록에서 고릅니다. 오늘/내일 버튼도 있습니다. 저장·표시·알림·집중 타이머는 한국시간을 사용하며, 기존 UTC 저장 데이터도 한국시간으로 변환합니다.

한 번 / 매일 / 평일(월~금, 공휴일 포함) / 매주(선택한 요일)를 지원합니다. 출근·퇴근 버튼은 각각 09:00/18:00 평일 반복을 미리 설정합니다. 반복 일정 완료 시 다음 회차로 넘어가며 같은 날 다음 회차를 미리 완료해 코인을 중복 수령할 수 없습니다. 앱을 여러 날 껐다 켜면 지난 반복 회차는 정리하고 오늘 또는 다음 회차를 표시합니다. 건너뛰기는 코인 없이 다음 회차로 이동합니다.

전날 미리 알림 스위치와 별도 시각(기본18:00)을 설정할 수 있습니다. 휴가 버튼은 내일09:00, 종일 모습, 전날18:00 알림을 미리 선택합니다. 전날에는 '내일은 휴가입니다~'라고 알려줍니다. 전날 지정 시각 이후 앱을 켜면 그날 안에서는 한 번 알려주며, 이미 지난 전날 알림은 뒤늦게 전달하지 않습니다.

일정별 PNG를 지정하면 당일 알림 시각부터 30분/1시간/2시간 동안 캐릭터가 바뀝니다. 종일 모습은 당일 자정부터 다음 자정까지 유지합니다. 전날 알림에도 지정 이미지가 잠깐 표시됩니다. 겹친 알림은 순서대로 표시하고, 겹친 모습은 종일 일정과 가장 최근 시작 일정을 우선합니다. 이미지가 없거나 기간이 끝나면 기본 캐릭터로 돌아갑니다. 목록 더블클릭 또는 일정 수정으로 변경합니다. 알림은 앱 실행 중 동작합니다.
